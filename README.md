# РЭН · документальный атлас и ОКУР

Локальная подготовка расширения Роснедр завершена 5 октября 2026 года. Основа — пакет v203; расширение Роснедр выполнено отдельными файлами в `rosnedra/`.

Главная карта: 91 узел и 363 связи. Структура Роснедр: 27 узлов и 18 связей. В ОКУР сохранены все 363 процесса и пять укрупнений по содержанию данных.

Дополнительно проверены связи Роснедр с Минздравом (лицензионные сведения через СМЭВ 3 для заключения на НМПТ) и Минфином (прогнозы бюджетных доходов через «Электронный бюджет»). Первая подтверждена карточкой услуги, вторая — документом об обмене за 2025 год. Фактическая отправка Роснедрами в 2026 году не утверждается. Тестовые подключения в СМЭВ не добавлены. Данные и источники этих связей находятся в `rosnedra/federal-links.js`.

## Файлы сайта

- `index.html` — загрузчик карты.
- `site_payload/v203/` — 18 частей исходного атласа; нужны все части.
- `rosnedra/` — данные расширения, структура и навигация.
- `okur/` — карта предметных контуров, данные и оформление.

Для размещения требуется сохранить относительные пути всех файлов. Для локального просмотра нужен веб-сервер: открытие `index.html` как обычного файла не обеспечивает загрузку частей карты.

## Подтверждения и ограничения

Региональные процессы, предусмотренные нормативными актами, показаны отдельно от документальных примеров. Исторические случаи не доказывают работу систем в 2026 году. Полная текущая редакция новгородского положения и часть адресных документов остаются неподтверждёнными; эти ограничения сохранены в карточках.

Проверены ссылки между файлами сайта, уникальность узлов и связей, структура Роснедр, переходы по регионам, данные в ОКУР и узкий экран 430 × 900. GitHub на этом этапе не обновлялся.
