# РЭН v244

Проверены все 81 прежний пункт фильтра каналов и привязки к 352 связям главной карты. В фильтре 52 уточнённых способа обмена / получения данных. 101 неподтверждённая привязка исключена из подсветки; все связи и исходные основания сохранены. Общие названия «личный кабинет» и «электронный документооборот» заменены конкретными сервисами там, где это позволяет источник. Авторизация, формат файлов и общая платформа не приравниваются к каналу.

У каждого пункта есть описание и кнопка «i» с процессами, статусом и ссылками на источники. Тестовый контур, нормативный эксперимент и исторические соглашения отмечены отдельно. Проверка документов не является проверкой текущего трафика или закрытых подключений. Часть первичных страниц повторно недоступна; такие ограничения сохранены в отчёте.

Проверены все 52 набора подсвечиваемых линий, все 352 карточки, источники каждого пункта, мобильное и настольное меню, пять классификаций ОКУР и возврат между слоями. Ошибок браузера не обнаружено.

В меню фильтров предлагаемой схемы оставлена только классификация «Какие сведения передаются»: пять типов и все виды сведений. Удалены выбор контура, поиск и список участников, сброс, пояснения и кнопка примера.

Меню содержания связей ОКУР перенесено с карты в «Фильтры». Исправлено заполнение каналов действующей схемы после ускоренной загрузки. Выбор типа сведений сохраняет открытое меню фильтров. Проверены оба слоя, выбор, сброс и возврат на телефоне и компьютере.

Выбор межконтурного пакета сохраняет внутренние связи на карте. Фильтрация по содержанию обмена продолжает действовать. Проверены все шесть пакетов во всех пяти классификациях и общем виде на компьютере и телефоне.

На телефонах выбор содержания связей предлагаемой схемы представлен компактным выпадающим списком. Сохранены пять типов сведений и общий вид; переключение не открывает боковую панель поверх карты. Проверены размеры 320, 390, 430 и 768 пикселей, а также настольное меню.

Версия v244 устраняет показ промежуточной карты во время загрузки. Отображается индикатор, затем готовая схема. Начальные скрипты объединены в один файл с именем по содержимому; карта строится один раз. Повторяющиеся строки данных сохраняются в общей таблице, неиспользуемые справочные поля матрицы не включаются в приложение.

Сохранены 77 участников, 352 связи, источники и внутренние структуры. Данные ОКУР запрашиваются при первом открытии предлагаемой схемы. Мобильные заголовки и поиск не перекрываются; нижняя панель переключает слои.

Полный [отчёт проверки каналов](archive/channel-audit-v244.md) содержит решения по всем прежним пунктам и их источники.

## Рабочие файлы

- index.html — небольшая начальная страница с индикатором загрузки.
- assets/app-v244-*.js — готовый исполняемый файл, подключаемый браузером.
- source/app.html — исходная разметка и базовый код для редактирования.
- source/build.cjs — сборщик опубликованной и автономной версии. Запуск из каталога проекта сайта: node source/build.cjs.
- data/site-data.js, rosnedra/, okur/ — исходные данные и модули; начальная страница отдельно их не загружает.
- okur/data.json и okur/domains.json — данные второго слоя, загружаемые по требованию.
- channels/audit-v244.js — компактный каталог и проверенные привязки каналов; channels/ui-v244.js — описания и просмотр оснований.
- archive/ — справочные материалы и история, не подключаемые браузером.

После изменения исходников запустите сборщик. Обновится index.html и файл в assets, а автономный HTML появится в dist. Каталог dist исключён из Git.

## Проверки

Итоговая модель данных идентична v238. Проверены все 77 карточек участников и 352 карточки связей, источники, внутренние виды остальных ведомств, структура и процессы Роснедр, пять классификаций ОКУР, возврат на главную, мобильные размеры 320–768 пикселей, настольный вид и отображение ошибки загрузки с повторной попыткой. При задержке 120 мс на файл в локальном сравнении готовность сократилась с 5700 до 844 мс. Это тестовое измерение, не гарантия скорости на любом подключении.
