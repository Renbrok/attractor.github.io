# РЭН v239

Версия v239 устраняет показ промежуточной карты во время загрузки. Отображается индикатор, затем готовая схема. Начальные скрипты объединены в один файл с именем по содержимому; карта строится один раз. Повторяющиеся строки данных сохраняются в общей таблице, неиспользуемые справочные поля матрицы не включаются в приложение.

Сохранены 77 участников, 352 связи, источники и внутренние структуры. Данные ОКУР запрашиваются при первом открытии предлагаемой схемы. Мобильные заголовки и поиск не перекрываются; нижняя панель переключает слои.

## Рабочие файлы

- index.html — небольшая начальная страница с индикатором загрузки.
- assets/app-v239-*.js — готовый исполняемый файл, подключаемый браузером.
- source/app.html — исходная разметка и базовый код для редактирования.
- source/build.cjs — сборщик опубликованной и автономной версии. Запуск из каталога проекта сайта: node source/build.cjs.
- data/site-data.js, rosnedra/, okur/ — исходные данные и модули; начальная страница отдельно их не загружает.
- okur/data.json и okur/domains.json — данные второго слоя, загружаемые по требованию.
- archive/ — справочные материалы и история, не подключаемые браузером.

После изменения исходников запустите сборщик. Обновится index.html и файл в assets, а автономный HTML появится в dist. Каталог dist исключён из Git.

## Проверки

Итоговая модель данных идентична v238. Проверены все 77 карточек участников и 352 карточки связей, источники, внутренние виды остальных ведомств, структура и процессы Роснедр, пять классификаций ОКУР, возврат на главную, мобильные размеры 320–768 пикселей, настольный вид и отображение ошибки загрузки с повторной попыткой. При задержке 120 мс на файл в локальном сравнении готовность сократилась с 5700 до 844 мс. Это тестовое измерение, не гарантия скорости на любом подключении.
